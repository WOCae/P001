# ACE-Step 1.5 サンプルプロンプト

`workflows/ace_step_1_5_music.json` の `TextEncodeAceStepAudio1.5` ノードに貼り付けて使います。
各ファイルの `### tags` を tags、`### lyrics` を lyrics 欄に入れ、先頭コメントの値を
bpm / timesignature / language / keyscale と `EmptyAceStep1.5LatentAudio` の長さに設定してください。

| ファイル | 内容 |
|---|---|
| 01_jpop_ja.txt | 日本語ポップス |
| 02_lofi_instrumental.txt | ローファイ・ヒップホップ(インスト) |
| 03_cinematic_orchestral.txt | シネマティック・オーケストラ(インスト) |
| 04_indie_folk_en.txt | 英語インディー・フォーク |
| 05_synthwave_en.txt | シンセウェイブ |

長さは90〜120秒程度が安定するとされています。いずれも生成確認はしていません。
